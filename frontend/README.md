In this task, you have to develop a Doctor Search Website. The objective of this task is to make you understand how to use Figma for designing web applications. How to export designs in HTML CSS using Anima App / Locofy App. You will also create a doctors database and create web services to search doctors. Finally you have to integrate web services with front end. At last step you have to deploy the running project on a web server. You can use 000webhost.com to create a Free Server.
